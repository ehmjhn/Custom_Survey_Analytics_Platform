# Custom-Survey-Analytics-Platform

Student Survey Management System

A web application intended for schools and colleges to facilitate the creation, distribution, and analysis of surveys between teachers and students. Designed to support dynamic question types, visual analytics, and straightforward user management. A Student Survey Management System to allow teachers to create customized surveys and assign to specific sections or classes, while students can efficiently complete assigned surveys and review their previous submissions. This will benefit an academic institution by allowing them to collect feedback, do evaluations, or measure educational outcomes all in an organized and data-driven way.

**USER ROLES AND INTERFACE**
**STUDENT** 
- Students are able to respond to assigned surveys and review the submission history. 

Screens Associated with Experience: 
- Sign up / Sign in 
- Assigned Surveys List 
- “Respond to Survey” Form (multiple questions types ) 
- History of my Responses 

**TEACHER / ADMIN**
-Teachers will be able to create and manage surveys, see responses, and analyze the results using visual reports that are built in. 

Screens Associated with Experience: 
- Sign in 
- Survey Builder (Question Creation, Settings) 
- Inbox for Responses 
- Analytics Dashboard 

**FEATURES**
A. Student Portal
**Assigned Survey List**: An area that references active state for surveys for students in classes or sections the student derives from. 
**Dynamic Survey Form**: Visits the multiple types of questions, which includes but is not limited to: 
- Multiple-choice questions 
- Likert Scale 
- Short Answer (with client validation and tracking) 
**Submitting & History**: A student can submit an assigned survey once and see their history of responses. 

B. Teacher/Admin Dashboard 
**Survey Builder**: A drag-and-drop functionality where a teacher can add or edit questions, deadline dates, or assign based on section. 
**Management of responses**: A view where individual student responses can be seen paginated and searchable. 
**Analytics & Visualization**: The ability to see live charts with utilization of Chart.js, while responding via: 
- Multiple Choice Pie Charts 
- Likert Scale Inequalities Bar Charts 
- Word Clouds for Main Responses 

Technologies Used:
**Frontend Technologies**: HTML, CSS,, JavaScript, JQuery (with Chart.js for Analytics) 
**Backend Technologies**: PHP (based on implementation) 
**Database**: MySQL (Xampp) 
**Other Tools**: Bootstrap, AJAX, JSON
